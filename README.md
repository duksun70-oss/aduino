# Arduino Study Repository

Arduino 예제 코드와 실습 프로젝트를 정리하기 위한 저장소입니다.

## 시작하기

현재 첫 번째 예제로 LED 점멸(Blink) 스케치를 포함합니다.

- 예제 경로: `examples/blink/blink.ino`
- 기본 보드 예시: Arduino Uno
- 동작: 내장 LED를 1초 간격으로 켜고 끕니다.

## 사용 방법

1. Arduino IDE를 실행합니다.
2. `examples/blink/blink.ino` 파일을 엽니다.
3. 사용하는 보드와 포트를 선택합니다.
4. 업로드 버튼을 눌러 보드에 전송합니다.

앞으로 센서, 초음파 거리 측정, 모터 제어, 시리얼 통신 등의 예제를 추가할 수 있습니다.
